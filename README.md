Overview
This project demonstrates a command-line Hangman game written in Rust, designed to enhance programming skills in systems development and algorithmic problem-solving.
The goal was to create an interactive application that showcases idiomatic Rust features, including:
⦁	Ownership and borrowing
⦁	Collections
⦁	Randomization
The game improves proficiency in building terminal applications while deepening understanding of Rust syntax and concepts.
This project provided insight into efficient data handling, error management, and user interactivity using Rust.
